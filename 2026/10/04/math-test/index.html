数学公式测试

在此学习如何在博客中渲染LaTeX风格数学公式，并继续学习更多LaTeX渲染方式，包括积分、矩阵、多行公式对齐等。

1. 求和、乘积和极限

求和：

[
\sum_{i=1}^{n}x_i
]

无限求和：

[
\sum_{n=1}^{\infty}\frac{1}{n^2}
]

乘积：

[
\prod_{i=1}^{n}x_i
]

极限：

[
\lim_{x\to0}f(x)
]

2. 积分

普通积分：

[
\int f(x),dx
]

定积分：

[
\int_a^b f(x),dx
]

二重积分：

[
\iint_D f(x,y),dx,dy
]

三重积分：

[
\iiint_V f(x,y,z),dV
]

闭合曲线积分：

[
\oint_C f(z),dz
]

注意积分中的：

这里的 \, 是一个小空格，所以：

通常比：

排版更规范。

3. 无穷、偏导和微分符号

无穷：

[
\infty
]

偏导：

[
\partial
]

例如：

[
\frac{\partial f}{\partial x}
]

梯度：

[
\nabla f
]

拉普拉斯形式：

[
\nabla^2 f
]

4. 矩阵

KaTeX 支持 LaTeX 的矩阵环境。

没有括号：

[
\begin{matrix}
a & b\
c & d
\end{matrix}
]

圆括号：

[
\begin{pmatrix}
a&b\
c&d
\end{pmatrix}
]

方括号：

[
\begin{bmatrix}
a&b\
c&d
\end{bmatrix}
]

这里：

表示分隔列，而：

表示换行。

比如一个 (3\times3) 矩阵：

[
\begin{bmatrix}
1&2&3\
4&5&6\
7&8&9
\end{bmatrix}
]

5. 分段函数

非常常用：

效果：

[
f(x)=
\begin{cases}
x^2,&x\ge0\
-x,&x<0
\end{cases}
]

这里同样是：

分列，

换行。

6. 多行公式对齐

KaTeX 支持类似：

效果：

[
\begin{aligned}
a &= b+c\
&= d+e\
&= f
\end{aligned}
]

& 可以理解为：

指定对齐位置。

所以通常放在等号前：

这样多行公式的等号会对齐。

例如推导：

[
\begin{aligned}
(x+1)^2
&=(x+1)(x+1)\
&=x^2+2x+1
\end{aligned}
]

7. 一个综合例子

比如二次方程求根公式：

效果：

[
x=
\frac{-b\pm\sqrt{b^2-4ac}}
{2a}
]

再比如正态分布：

效果：

[
f(x)=
\frac{1}{\sigma\sqrt{2\pi}}
\exp\left(
-\frac{(x-\mu)^2}{2\sigma^2}
\right)
]
